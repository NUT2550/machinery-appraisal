# 🏗️ ระบบประเมินราคารับซื้อเครื่องจักร (เหมาคัน)

เว็บแอปสำหรับประเมินราคารับซื้อเครื่องจักรเก่า/เศษเหล็ก แบบเหมาคัน —
คำนวณรายรับจากน้ำหนักสินค้า หักด้วยต้นทุนการย่อย (อิงตามเวลา) แล้วสรุปเป็น **ราคาเฉลี่ยต่อกิโลกรัม** เพื่อใช้ตัดสินใจรับซื้อ

🔗 **ลองใช้งาน:** https://sage-longma-19002e.netlify.app/

---

## ✨ ความสามารถ

- **สรุปผลลัพธ์แบบเรียลไทม์** — น้ำหนักสุทธิ · จำนวนเงินสุทธิหลังหักค่าใช้จ่าย · ราคาเฉลี่ยต่อกิโลกรัม
- **ตารางประเมินสินค้า (รายรับ)** — เพิ่ม/ลบรายการได้ คำนวณรวมเป็นเงินอัตโนมัติ
- **ตารางค่าใช้จ่ายการย่อย (รายจ่าย)** — 4 วิธีการ ต้นทุนต่อนาที **แก้ไขได้ตามหน้างาน**
- **บันทึก + ประวัติย้อนหลัง** — ค้นหา โหลดกลับมาแก้ไข และลบได้ (ยืนยัน 2 ขั้นก่อนลบ)
- **ฐานข้อมูลคลาวด์** — เชื่อม Supabase ได้จากในตัวแอป (ซิงก์ทุกเครื่อง) · ถ้ายังไม่เชื่อมจะบันทึกใน localStorage อัตโนมัติ
- **โหมดมืด/สว่าง** — จำค่าที่เลือกไว้ · รองรับ Responsive ทั้งมือถือและคอมพิวเตอร์

## 🧮 สูตรคำนวณ

| รายการ | สูตร |
|---|---|
| รวมเป็นเงิน (รายแถว) | `น้ำหนัก (กก.) × ราคาขายส่ง (บาท/กก.)` |
| ค่าใช้จ่าย ข้อ 1–3 | `ต้นทุนคงที่/นาที × เวลาที่ใช้ (นาที)` |
| ค่าใช้จ่าย ข้อ 4 (ค่าแรง) | `ต้นทุนคงที่/นาที × เวลาที่ใช้ × จำนวนคนทำ` |
| จำนวนเงินสุทธิ | `รวมรายรับ − รวมรายจ่าย` |
| ราคาเฉลี่ยต่อกิโลกรัม | `จำนวนเงินสุทธิ ÷ น้ำหนักสุทธิ` |

## 🛠 เทคโนโลยี

- **Vue 3** (ผ่าน CDN) — ไฟล์ HTML เดียวจบ ไม่ต้อง build
- **Supabase** (PostgreSQL + RLS) — เก็บข้อมูลแบบ `jsonb`
- **Fonts:** Kanit + Sarabun (Fontsource CDN)
- **Deploy:** Netlify

## 🚀 การใช้งาน

**แบบเร็วที่สุด** — บันทึกโค้ดเป็น `index.html` แล้วเปิดด้วยเบราว์เซอร์ได้ทันที

**Deploy ขึ้นเน็ต (ฟรี)**
1. ลากไฟล์ `index.html` วางที่ https://app.netlify.com/drop
2. หรือเชื่อม GitHub repo นี้กับ Netlify → แก้โค้ดแล้วเว็บอัปเดตอัตโนมัติ

## 🗄 การเชื่อมต่อฐานข้อมูล Supabase

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) แล้วรัน SQL นี้ใน SQL Editor:

```sql
create table appraisal_records (
  id         uuid primary key default gen_random_uuid(),
  ref        text,
  created_at timestamptz default now(),
  payload    jsonb not null
);

alter table appraisal_records enable row level security;

create policy "อนุญาตทุกผู้ใช้ (anon key)"
on appraisal_records for all
using (true) with check (true);
